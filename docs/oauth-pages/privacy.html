Privacy policy — foldersync

Last updated: October 2026

foldersync is a personal tool used only by its owner to synchronize files between the owner's own computers and the owner's own Google Drive.

What data is accessed

With the owner's permission, the app accesses the owner's Google Drive (scope https://www.googleapis.com/auth/drive) solely to upload, download, update and delete files in the folders the owner has chosen to synchronize.

How data is used and stored

  • Files are transferred only between the owner's computers and the owner's Google Drive.
  • Access tokens are stored locally on the owner's computers in the rclone configuration file.
  • No data is sent to the developer or any third party. There are no analytics, advertising or tracking.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
